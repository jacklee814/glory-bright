# 設計決策

- 使用 Astro 靜態輸出與公開 GitHub Pages，沒有後端、表單或第三方 API。
- 產品 URL 以型號維持扁平 `/p/{model}/`；分類路由保留階層。
- 不提供產品篩選、產品比較與電話／E-mail 詢價 CTA（2026-09-20 業主決定縮減範圍）。原規格書與實作計畫的「漸進增強互動」整段作廢，`Catalog.astro`、`Compare.astro`、`scripts/filter.ts`、`scripts/compare.ts` 已移除，改以 `ProductGrid.astro` 純列表呈現。
- Header 的型號搜尋保留。搜尋與篩選是不同功能，縮減範圍不含搜尋。
- 頁尾與首頁的公司聯絡資訊（電話、傳真、E-mail）保留，那是公司資訊而非詢價入口。
- 產品資料由 `tools/scraper` 自舊站 `www.glory-bright.com.tw` 遷移而來，snapshot 為冷備份並隨 repo 保存。
- 不匯入舊站售價。舊站售價為 2020 年資料，且新站定位為無報價、無購物車的型錄。
- 開關面板以舊站圖片料號（如 `010102`）作為型號，因舊站開關無型號欄位與明細頁。
- 開關描述原樣保留為字串陣列，不強行結構化；舊站描述格式不一致，硬解會誤判。
- 跳過舊站 0 件的子分類「光源／1121321」與「懸吊式」；軌道燈下的「盒_燈」「模組式_」正名為「盒燈」「模組式」。
- 產品圖沿用舊站原始尺寸轉為 WebP，不放大；待業主提供高解析原圖後替換。舊站跨產品共用的規格示意圖只轉檔一次並共用路徑。
- 公司地址為「台北市內湖區民權東路六段180巷6號5樓之13」，由業主於 2026-09-22 確認。舊站頁尾寫康寧路三段265巷33號1F、聯絡頁寫民權東路六段180巷6號5樓之12，兩者皆與此不符，以業主提供者為準。
- 授權經銷品牌（東亞照明、金鍏電子、城市照明、舞光）由業主提供，顯示於頁尾。
- 最新消息於 2026-09-21 重新加入。`news` content collection 由人工在 `site/src/content/news/` 維護，不經 scraper；檔名帶日期前綴以利排序，網址只取後面的 slug。明細頁排版為 標題 → 灰色日期 → 純文字內容 → 選填圖片。
- `site/src/content/news/` 目前 3 則為示範內容，正式網域上線前必須由業主替換。
